## ネタバレ（遊ぶ前の人は読まないでください）

このゲームは、最後におどろかせるジョーク（ドッキリ）です。最終レベルの細い道（または最終レベルで3回目のミス）で、こわい顔の画像と大きな音が急に出ます。

- 最初の画面に、次の注意を書いています。「急に大きな音が出ることがあります。心臓の弱い方、妊娠中の方、体調のすぐれない方、小さなお子さまはご遠慮ください。イヤホンの方は音量をひかえめに。歩きながら・運転中は遊ばないでください。」
- 最初の画面の「いちばん大きい音を確かめる」ボタンは、ゲームの中でいちばん大きい音と同じくらいの大きさで鳴ります。この音で音量を合わせてください。
- 激しい点滅は使っていません（画像がゆれるのは最初の約0.2秒だけです。端末の「動きを減らす」設定では、ゆれも拡大も止まります）。
- 人に送るときは、相手の体調と、いる場所（電車・職場など）に気をつけてください。

## 中身

- `index.html` 1枚で動きます。外部の読み込みはありません。
- 音楽・効果音・叫び声は、ファイルを使わず、ブラウザの中で作って鳴らしています。
- 顔の画像（`face.jpg`、`face2.jpg`〜）は、画像生成AIに文章だけで作らせた架空の顔です。実在の人物や、既存の作品のキャラクターを指定して作ったものではありません。
- よくある「迷路ドッキリ」の形式ですが、既存のゲームの画像・音・迷路・名前は使っていません。迷路・音・プログラムは一から作っています。
- 自己ベスト・遊んだ回数・集めた称号・前回出た顔は、その端末のブラウザにだけ保存します。このページがデータを集めたり送ったりすることはありません。配信元の GitHub には、アクセスの記録（IPアドレス）が残ります。

顔の画像を足すときは、`_inbox` フォルダに画像を入れて、次を実行します（Python と Pillow が必要です）。

```bash
python tools/add_faces.py
```

リンクを貼ったときに出る画像（`ogp.png`）は、次で作ります（Windows で、Python と Pillow、文字の Noto Sans JP が必要です）。ファイル名のあとの文字が、作った人の表示になります（付けなければ、表示なしの画像になります）。

```bash
python tools/make_ogp.py ogp.png "作った人：バルス大佐（@baris250209）"
```
