# 集中力テスト

青い点を、かべにふれずにゴールまで運ぶタイムアタックです。全3レベル。スマホのブラウザで開くだけで遊べます。

https://baris250209.github.io/shuchu-test/

## ネタバレ（遊ぶ前の人は読まないでください）

このゲームは、最後におどろかせるジョーク（ドッキリ）です。最終レベルの細い道で、こわい顔の画像と大きな音が急に出ます。

- 最初の画面に「音が出ます。心臓の弱い方、体調のすぐれない方はご遠慮ください。」と書いてあります。
- 激しい点滅は使っていません（画像がゆれるだけです。端末の「動きを減らす」設定では、ゆれも止まります）。
- 人に送るときは、相手の体調や場所に気をつけてください。

## 中身

- `index.html` 1枚で動きます。外部の読み込みはありません。
- 音楽・効果音・叫び声は、ファイルを使わず、ブラウザの中で作って鳴らしています。
- 顔の画像（`face.jpg`、`face2.jpg`〜）は、画像生成AIで作った架空の顔です。実在の人物や、既存の作品のキャラクターではありません。
- 既存のゲームの再現ではありません。迷路・音・プログラムは一から作っています。
- 自己ベスト・遊んだ回数・集めた称号は、その端末のブラウザにだけ保存します。データの収集や送信は行いません。

## テスト

```bash
node tests/test_maze.mjs index.html
```

```bash
node tests/test_titles.mjs index.html
```

顔の画像を足すときは、`_inbox` フォルダに画像を入れて、次を実行します（Python と Pillow が必要です）。

```bash
python tools/add_faces.py
```
